使用与分析说明

保持安静，关闭音乐；校准时不说话。音量为 FFT 高频段累积能量的相对 dB，不是声压计读数。百分制公式：100 − 8×波动标准差 − 3×趋势幅度 − 8×中断次数，最低 0 分；系数为本工具的练习启发规则。每 100 毫秒平均 3–10 kHz 高频段声音能量，起伏采用取中间约 75% 的电平标准差；低于底噪 +8 dB 且持续至少 0.3 秒计为可能中断。起伏 ≤2 dB / ≤4 dB 为本工具的参考分级，无临床验证，不用于诊断。末尾低电平从时长及评估中移除，单独作为收尾，不计中断。

浏览器会尝试关闭降噪、回声消除与自动增益，但设备可能不支持。请只在同一设备、同一距离下比较。自然呼吸，不憋气、不硬撑；不舒服就停止。

电脑：下载后用 Chrome、Edge 或 Safari 打开。iPhone：需通过 HTTPS 网页在 Safari 中打开；文件预览可能无法授权麦克风。
